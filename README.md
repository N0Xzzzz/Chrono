# Chrono

A polished, responsive digital clock with focused timekeeping tools.

## Features

- Live local time and date with 12/24-hour and seconds preferences
- Light and dark themes, plus fullscreen mode
- Stopwatch with pause, resume, lap, and reset
- Countdown timer with pause, resume, and reset
- Saved display preferences

## Technologies

HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern web browser. No build step or server is required.
